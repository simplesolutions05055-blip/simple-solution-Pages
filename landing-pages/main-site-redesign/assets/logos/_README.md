# Client / Partner Logos

זה המקום ללוגואים של חברות שאיתן אתה עובד. הם יוצגו ב-marquee הגולל בעמוד הבית (אזור "SIMPLE PLAN · אוטומציות · SOCIAL MEDIA · ניהול קמפיינים").

## הנחיות העלאה

| נושא | המלצה |
|---|---|
| **פורמט** | SVG (הכי טוב - חד בכל גודל) או PNG עם רקע שקוף |
| **שם קובץ** | אנגלית, kebab-case: `client-name.svg`, `acme-corp.png` |
| **גודל** | SVG: כל גודל. PNG: ~400x160 פיקסלים (יחס 5:2) |
| **רקע** | שקוף (חובה) |
| **גובה ויזואלי** | יישמר אוטומטית ב-CSS על 48px |

## אחרי שאתה מעלה — מה אני אעשה

1. ה-marquee הגולל יוחלף מטקסט ללוגואים מעוצבים
2. כל לוגו יקבל ריחוף + אפקט hover
3. נוסיף "Logos Wall" סקציה נפרדת באתר (אופציונלי)
